## 日本語

## この主題領域について

このディレクトリでは、日本国内の学校・教育機関等を識別するために使用される各種コード体系に関する二次データを収録します。

コード体系ごとに、その作成・管理主体、目的、対象範囲、更新方法等が異なるため、それぞれを独立した下位領域として管理します。

各コード体系の一次情報源、利用条件、データ構造、加工方法等については、それぞれのREADMEおよびメタデータを参照してください。

## 収録するコード体系

現在、次のコード体系を収録しています。

- [`mext-school-codes/`](mext-school-codes/) — 文部科学省「学校コード」

今後、異なる機関・制度による学校・教育機関等のコード体系を収録する場合は、この階層に追加します。

# English

This subject domain contains secondary data concerning code systems used to identify schools, educational institutions, and related entities in Japan.

## About This Subject Domain

This directory contains secondary data concerning various code systems used to identify schools, educational institutions, and related entities in Japan.

Because each code system may differ in its responsible organization, purpose, scope, and update process, each system is maintained as an independent subdomain.

For information about primary sources, terms of use, data structures, and processing methods, see the README and metadata for each code system.

## Included Code Systems

The following code system is currently included:

- [`mext-school-codes/`](mext-school-codes/) — 「学校コード」 published by the Ministry of Education, Culture, Sports, Science and Technology (MEXT)

Additional code systems maintained under different institutions or frameworks may be added at this level in the future.

## Maintenance and Project Information

This subject domain is maintained as part of the `open-secondary-data` project.

For project maintainership, contact information, repository-wide policies on terms of use, and overall design principles, see the [root README](../README.md).
