Open Secondary Data

Traceable, reusable secondary data

OPEN DATA PROJECT

公開情報を、
たどれるデータへ。

Open Secondary Data は、公開されている一次情報源をもとに、 データを再利用しやすい形式へ整理・構造化するプロジェクトです。

データそのものだけでなく、 「どの情報源から、どのような処理を経て作られたのか」 を確認できることを重視しています。

データを、出典から切り離さない。

01

Primary Source

可能な限り一次情報源を保存・記録し、 公開元や取得日などの情報を明示します。

02

Structured Data

一次情報を整理・正規化し、 CSV、JSON、YAMLなど再利用しやすい形式で提供します。

03

Traceability

二次データから一次情報源や処理過程へ 遡ることのできる構造を目指します。

DATASETS

公開中のデータセット

データセットを読み込んでいます。

WORKFLOW

データが公開されるまで

  1. 01 一次情報源を取得
  2. 02 データを整理・正規化
  3. 03 機械的に検証
  4. 04 前回版との差分を確認
  5. 05 人間によるレビュー

ABOUT

一次情報を代替するためのデータではありません。

本プロジェクトが提供するのは、 公開された一次情報を整理・構造化した二次データです。 必要に応じて、各データセットに記載された一次情報源も確認してください。

データの来歴と処理過程を確認でき、 将来もう一度同じ処理を再現できることを重視しています。
